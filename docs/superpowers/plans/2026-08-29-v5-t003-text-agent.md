# V5-T003 Text Instruction Agent Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a single-turn, fail-closed text instruction agent that converts “帮我拿杯子” into a validated `plastic_cup + pick + {}` command and dispatches the existing MuJoCo dynamic cup pick-place runtime only after deterministic gates and explicit double authorization.

**Architecture:** Keep provider-specific HTTP calls behind `PlannerPort`, parse but do not trust their JSON, and pass exactly one candidate through an immutable `TaskCommand` validator. A fixed-code `TextAgent` resolves the only supported capability, handles preview and double authorization, claims `request_id` before the first dispatch attempt, and invokes a typed Python executor adapter without constructing shell commands. The executor preserves the current `dynamic_cup_pick_place` runtime's session, reset-epoch, evidence-root, source, and install provenance requirements.

**Tech Stack:** Python 3.10+, frozen dataclasses, `typing.Protocol`, standard-library `urllib.request`, ROS 2 Jazzy `ament_python`, pytest, existing `so101_demo_py` dynamic MuJoCo runtime.

**Spec:** `/Users/matianyi/Projects/robot_demo_001/docs/superpowers/specs/2026-08-29-v5-t003-text-agent-design.md`

## Global Constraints

- The only validated command shape is exactly `target_object=plastic_cup`, `action=pick`, and a constraint object whose keys and values are from the V5 schema.
- A syntactically valid provider JSON value is validated once after `PlannerChain`; semantic validation failures return `COMMAND_INVALID` and do not trigger fallback.
- Provider transport failure, timeout, empty content, malformed response envelope, or invalid JSON may trigger Ollama exactly once; both failures return `PLANNER_FAILED` and never call the executor.
- DeepSeek defaults to `deepseek-v4-flash`, JSON Output, non-thinking mode, temperature `0`, and sends only the current bounded instruction plus the public schema prompt.
- Ollama defaults to local `http://127.0.0.1:11434/api/chat`, model `qwen3.5:4b`, `stream=false`, the shared JSON schema in `format`, and temperature `0`.
- API keys come only from `DEEPSEEK_API_KEY`; raw credentials, environment dumps, raw provider bodies, local paths, ROS state, images, depth, TF, and joint data are never sent or logged.
- V5-T003 has no consumer for `spatial_relation` or `speed`; the validator recognizes allowed values, but Dispatcher rejects every non-empty `constraints` object.
- Preview is the default and never imports ROS or calls the executor.
- Execution requires `--mode execute` and `--execute` together, `backend=mujoco`, an evidence root, a runtime session ID, and an expected reset epoch.
- `request_id` is claimed immediately before calling the executor and remains claimed after success or failure, so the Agent never auto-retries a physical request.
- `RUNTIME_COMPLETED` reports the existing runtime return code only; V5-T003 does not reinterpret it as proof of V5-T005 physical pick-place success.
- Preserve the pre-existing untracked `src/so101_demo_py/docs/planner-schema.md`, parent-repository learner/model documents, ai-station RGB-D experiment ledger, and existing `codex`/`codex-cua` tmux sessions.
- Use the single registered evidence root `/tmp/so101-debug-v5-t003-text-agent-20260829-164105/`; do not create another task evidence root and do not delete evidence.
- Do not use provider SDKs, Pydantic, shell execution, arbitrary CLI argument forwarding, `gh`, or `ament_uncrustify --reformat`.

```python
from __future__ import annotations

from dataclasses import dataclass
from typing import Final, Literal

TargetObject = Literal["plastic_cup"]
TaskAction = Literal["pick"]

TASK_COMMAND_JSON_SCHEMA: Final[dict[str, object]] = {
    "type": "object",
    "additionalProperties": False,
    "required": ["target_object", "action", "constraints"],
    "properties": {
        "target_object": {"type": "string", "enum": ["plastic_cup"]},
        "action": {"type": "string", "enum": ["pick"]},
        "constraints": {
            "type": "object",
            "additionalProperties": False,
            "properties": {
                "spatial_relation": {"type": "string", "enum": ["left", "right", "center", "nearest"]},
                "speed": {"type": "string", "enum": ["slow", "normal"]},
            },
        },
    },
}


class CommandValidationError(ValueError):
    def __init__(self, reason: str) -> None:
        super().__init__(reason)
        self.code = "COMMAND_INVALID"
        self.reason = reason


@dataclass(frozen=True, slots=True)
class TaskCommand:
    target_object: TargetObject
    action: TaskAction
    constraints: tuple[tuple[str, str], ...]

    def to_dict(self) -> dict[str, object]:
        return {
            "target_object": self.target_object,
            "action": self.action,
            "constraints": dict(self.constraints),
        }


def validate_instruction(value: object, max_chars: int = 200) -> str:
    if not isinstance(value, str):
        raise CommandValidationError("instruction must be a string")
    instruction = value.strip()
    if not instruction or len(instruction) > max_chars:
        raise CommandValidationError("instruction length is invalid")
    return instruction


def validate_task_command(candidate: object) -> TaskCommand:
    if not isinstance(candidate, dict) or set(candidate) != {"target_object", "action", "constraints"}:
        raise CommandValidationError("top-level fields are invalid")
    if candidate["target_object"] != "plastic_cup" or candidate["action"] != "pick":
        raise CommandValidationError("object or action is unsupported")
    constraints = candidate["constraints"]
    if not isinstance(constraints, dict):
        raise CommandValidationError("constraints must be an object")
    allowed = {
        "spatial_relation": {"left", "right", "center", "nearest"},
        "speed": {"slow", "normal"},
    }
    for key, value in constraints.items():
        if key not in allowed or not isinstance(value, str) or value not in allowed[key]:
            raise CommandValidationError("constraint is unsupported")
    return TaskCommand("plastic_cup", "pick", tuple(sorted(constraints.items())))
```

- [ ] **Step 4: Add the exact-once fallback chain**

```python
from dataclasses import replace

from ..ports.task_planner import PlannerCandidate, PlannerPort, PlannerProviderError


class PlannerChain:
    def __init__(self, primary: PlannerPort, fallback: PlannerPort) -> None:
        self._primary = primary
        self._fallback = fallback

    def plan(self, instruction: str) -> PlannerCandidate:
        try:
            return self._primary.plan(instruction)
        except PlannerProviderError as primary_error:
            try:
                candidate = self._fallback.plan(instruction)
            except PlannerProviderError as fallback_error:
                raise PlannerProviderError("PLANNER_CHAIN_FAILED") from fallback_error
            return replace(candidate, metadata=replace(candidate.metadata, fallback_used=True))
```

```python
from __future__ import annotations

import json
from collections.abc import Mapping
from urllib.error import HTTPError, URLError
from urllib.request import Request, urlopen

from ...ports.task_planner import PlannerProviderError


def post_json(url: str, headers: Mapping[str, str], body: dict[str, object], timeout_s: float) -> dict[str, object]:
    request = Request(
        url,
        data=json.dumps(body, ensure_ascii=False).encode("utf-8"),
        headers={"Content-Type": "application/json", **headers},
        method="POST",
    )
    try:
        with urlopen(request, timeout=timeout_s) as response:
            payload = json.loads(response.read().decode("utf-8"))
    except (TimeoutError, HTTPError, URLError, UnicodeDecodeError, json.JSONDecodeError) as error:
        raise PlannerProviderError("PROVIDER_TRANSPORT_FAILED") from error
    if not isinstance(payload, dict):
        raise PlannerProviderError("PROVIDER_RESPONSE_INVALID")
    return payload
```

```python
class DeepSeekPlanner:
    def __init__(
        self,
        api_key: str,
        *,
        model: str = "deepseek-v4-flash",
        endpoint: str = "https://api.deepseek.com/chat/completions",
        timeout_s: float = 8.0,
        transport=post_json,
    ) -> None:
        self._api_key = api_key
        self._model = model
        self._endpoint = endpoint
        self._timeout_s = timeout_s
        self._transport = transport

    def plan(self, instruction: str) -> PlannerCandidate:
        if not self._api_key:
            raise PlannerProviderError("DEEPSEEK_CREDENTIAL_MISSING")
        started = time.perf_counter_ns()
        payload = self._transport(
            self._endpoint,
            {"Authorization": f"Bearer {self._api_key}"},
            {
                "model": self._model,
                "messages": [
                    {"role": "system", "content": PLANNER_SYSTEM_PROMPT},
                    {"role": "user", "content": instruction},
                ],
                "response_format": {"type": "json_object"},
                "thinking": {"type": "disabled"},
                "temperature": 0,
                "max_tokens": 128,
            },
            self._timeout_s,
        )
        try:
            content = payload["choices"][0]["message"]["content"]
            usage = payload.get("usage", {})
        except (KeyError, IndexError, TypeError) as error:
            raise PlannerProviderError("DEEPSEEK_RESPONSE_INVALID") from error
        metadata = PlannerMetadata(
            "deepseek",
            self._model,
            (time.perf_counter_ns() - started) // 1_000_000,
            usage.get("prompt_tokens"),
            usage.get("completion_tokens"),
            usage.get("prompt_cache_hit_tokens"),
            False,
        )
        return PlannerCandidate(decode_candidate(content), metadata)
```

```python
class AgentStatus(str, Enum):
    PLANNER_FAILED = "PLANNER_FAILED"
    COMMAND_INVALID = "COMMAND_INVALID"
    DISPATCH_REJECTED = "DISPATCH_REJECTED"
    DISPATCH_PREVIEW = "DISPATCH_PREVIEW"
    RUNTIME_STARTED = "RUNTIME_STARTED"
    RUNTIME_FAILED = "RUNTIME_FAILED"
    RUNTIME_COMPLETED = "RUNTIME_COMPLETED"


@dataclass(frozen=True, slots=True)
class AgentRequest:
    request_id: str
    instruction: str
    mode: str
    execute: bool
    backend: str


@dataclass(frozen=True, slots=True)
class AgentResult:
    request_id: str
    status: AgentStatus
    reason_code: str | None
    metadata: PlannerMetadata | None
    command: dict[str, object] | None
    capability: str | None
    dispatch: bool
    runtime_session_id: str | None

    def to_dict(self) -> dict[str, object]:
        result: dict[str, object] = {
            "request_id": self.request_id,
            "status": self.status.value,
            "dispatch": self.dispatch,
        }
        if self.reason_code is not None:
            result["reason_code"] = self.reason_code
        if self.metadata is not None:
            result["planner"] = {
                "provider": self.metadata.provider,
                "model": self.metadata.model,
                "latency_ms": self.metadata.latency_ms,
                "input_tokens": self.metadata.input_tokens,
                "output_tokens": self.metadata.output_tokens,
                "cache_hit_tokens": self.metadata.cache_hit_tokens,
                "fallback_used": self.metadata.fallback_used,
            }
        if self.command is not None:
            result["command"] = self.command
        if self.capability is not None:
            result["capability"] = self.capability
        if self.runtime_session_id is not None:
            result["runtime_session_id"] = self.runtime_session_id
        return result


class TextAgent:
    def __init__(self, planner: PlannerPort, executor: PickPlaceExecutorPort, dispatcher: TaskDispatcher | None = None) -> None:
        self._planner = planner
        self._executor = executor
        self._dispatcher = dispatcher or TaskDispatcher()
        self._claimed_request_ids: set[str] = set()

    def handle(self, request: AgentRequest) -> AgentResult:
        if not request.request_id.strip():
            return AgentResult(request.request_id, AgentStatus.DISPATCH_REJECTED, "REQUEST_ID_INVALID", None, None, None, False, None)
        try:
            instruction = validate_instruction(request.instruction)
        except CommandValidationError:
            return AgentResult(request.request_id, AgentStatus.COMMAND_INVALID, "INPUT_INVALID", None, None, None, False, None)
        try:
            planned = self._planner.plan(instruction)
        except PlannerProviderError:
            return AgentResult(request.request_id, AgentStatus.PLANNER_FAILED, "PLANNER_CHAIN_FAILED", None, None, None, False, None)
        try:
            command = validate_task_command(planned.value)
        except CommandValidationError:
            return AgentResult(request.request_id, AgentStatus.COMMAND_INVALID, "COMMAND_INVALID", planned.metadata, None, None, False, None)
        try:
            dispatch_request = self._dispatcher.resolve(command, request.request_id)
        except DispatchRejectedError:
            return AgentResult(request.request_id, AgentStatus.DISPATCH_REJECTED, "CONSTRAINT_UNCONSUMED", planned.metadata, command.to_dict(), None, False, None)
        if request.mode == "preview" and not request.execute:
            return AgentResult(request.request_id, AgentStatus.DISPATCH_PREVIEW, None, planned.metadata, command.to_dict(), dispatch_request.capability, False, None)
        if request.mode != "execute" or not request.execute:
            return AgentResult(request.request_id, AgentStatus.DISPATCH_REJECTED, "EXPLICIT_EXECUTE_REQUIRED", planned.metadata, command.to_dict(), dispatch_request.capability, False, None)
        if request.backend != dispatch_request.backend:
            return AgentResult(request.request_id, AgentStatus.DISPATCH_REJECTED, "BACKEND_NOT_QUALIFIED", planned.metadata, command.to_dict(), dispatch_request.capability, False, None)
        if request.request_id in self._claimed_request_ids:
            return AgentResult(request.request_id, AgentStatus.DISPATCH_REJECTED, "DUPLICATE_REQUEST_ID", planned.metadata, command.to_dict(), dispatch_request.capability, False, None)
        self._claimed_request_ids.add(request.request_id)
        runtime = self._executor.dispatch(dispatch_request)
        status = AgentStatus.RUNTIME_COMPLETED if runtime.exit_code == 0 else AgentStatus.RUNTIME_FAILED
        return AgentResult(request.request_id, status, None if runtime.exit_code == 0 else "RUNTIME_FAILED", planned.metadata, command.to_dict(), dispatch_request.capability, True, runtime.runtime_session_id)
```

Claim `request_id` by adding it to a private set immediately before `executor.dispatch()`. Map exit code `0` to `RUNTIME_COMPLETED` and every nonzero code to `RUNTIME_FAILED`; do not retry or remove the ID.
