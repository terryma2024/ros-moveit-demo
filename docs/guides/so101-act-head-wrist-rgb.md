# SO-101 ACT head and wrist RGB pipeline (superseded)

This guide described the ACT tooling when nothing had been collected or trained and the only rig was head plus wrist.
That is no longer true. Two rigs exist (head-wrist and side-wrist), 100 and 103 episodes have been collected and sealed,
and three policies have been trained to completion (two of them rolled out).

Read `docs/guides/so101-act-data-collection-and-training-architecture.md` instead. It covers the components, the
workflows, the configuration keys, the evidence and hash chain, the measured performance and the known issues. The
commands this file used to document (`act_sample`, `act_inference_worker`, `act_session`, `act_evaluate` and the
qualification report tools) are summarised in its section 9.

The file stays so existing links keep working.
