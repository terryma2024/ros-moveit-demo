## 任务目标与验收边界

目标是在 Gazebo 中完成一次可信的 SO-101 全流程：

```text
DESCEND -> CLOSE -> ATTACH -> LIFT -> TRANSFER -> PLACE -> DETACH -> DONE
```

最终验收不仅要求状态机输出 `DONE`，还要求：

- 固定指和活动指均形成合理的物理接触；
- 杯子在抓取阶段的平移漂移不超过 3 mm；
- 杯子姿态漂移不超过 0.035 rad；
- 精确网格穿透不超过 0.8 mm；
- attach 时没有明显瞬移；
- Gazebo、MoveIt Planning Scene、controller、joint/TF 和新鲜视觉证据相互一致；
- 完整链路至少成功运行，而不是只通过静态几何或单元测试。

## 当前结论

最终目标尚未完成。当前没有证据证明任何参数组合能够稳定完成完整抓取、抬升、搬运和放下。

### 已观察事实（OBSERVED）

1. 杯子的碰撞模型具有空心区域，不是实心圆柱阻止夹爪进入。
2. 将指尖 visual 临时替换为 collision 形状后，未观察到明显的碰撞原点错位。
3. URDF 到 Gazebo 实际 SDF 的位姿审计中，指尖 visual 与 collision 的 pose 差为零，包围范围相符。
4. 夹爪下降/闭合过程会改变杯子位姿。
5. 固定指与活动指的有效接触高度相差约 6.273 mm，产生的力矩方向与杯子实际倾斜方向一致。
6. Gazebo/Bullet 在精确网格尚未接触时可能已经报告 contact；早期 contact 中包含 speculative manifold，不能直接等同于真实物理穿透。
7. 杯底摩擦系数改为 `mu=0.3` 后出现过单次改善，但无法复现，已回退。

### 当前推断（INFERRED）

杯子受到扰动的主要机制更可能是不对称的接触几何和抓取姿态，而不是：

- 杯子内部错误地被建模成实心；
- Blender visual 与 Gazebo collision 使用了不同原点；
- 杯体接缝；
- 单纯的杯底摩擦不足。

该判断已有多项证据支持，但尚未通过同一配置的稳定 RED/GREEN 动态 A/B 达到“根因已确认”门槛。

## 方法复盘

### 1. 主指标发生漂移

排障长期停留在 `DESCEND/CLOSE` 的亚毫米指标，没有持续以完整抓取放下作为可见主指标。局部分析越来越精细，但没有产生端到端结果。

### 2. 过早进入高维微调

pitch、TCP Y、q6、摩擦和 attach pose 相互耦合，却被长时间按一维变量串行搜索。直到后期才联合计算 Y 与 q6，导致前期实验信息增益偏低。

### 3. 混淆证据语义

曾混用以下数据，导致无效扫描和返工：

- Bullet speculative contact 与真实物理接触；
- raw contact depth 与精确网格相交；
- 原始 CLOSE 指标与恢复动作后的指标；
- 理想目标位姿与同步真实关节位姿；
- pre-attach pose 与 attach 后相对位姿。

后续每个指标必须附带采样时刻、所属进程、数据源和物理含义。

### 4. 缺少统一实验台账

配置、代码版本、运行时间、关键指标和结论散落在日志与 `/tmp` 文件中。方向修正后无法快速标记哪些旧结论已经失效，容易重复验证。

### 5. 远程 agent 缺少硬停止条件

远程 Codex 被赋予开放式“持续解决”的目标，但没有受到明确的实验次数、时间盒和停止条件约束。监督过于追随局部分析，而不是要求短周期决策。

### 6. 诊断门槛与最终验收门槛混用

最终严格验收是必要的，但探索阶段的每个 A/B 都试图同时满足全部最坏情况门槛，降低了实验速度。诊断实验首先应回答某个变量是否改变故障机制。

### 7. 视觉排障投入失衡

镜头调整、窗口控制和 collision-as-visual 消耗了较多时间。数值位姿审计已经足以排除部分原点偏移假设后，继续优化画面没有提供相称的新证据。

### 8. 未执行收敛规则

连续两轮没有新增区分性证据时，本应停止该参数路线、输出证据矩阵并重新建模；实际工作继续进行了更小幅度的偏移测试。

## 建议的重启流程

恢复任务时采用硬时间盒，不再无限微调：

1. 重新确认 ai-station 的 branch、commit、dirty status、安装产物和相关进程。
2. 建立单一实验台账，每次记录唯一配置 ID、唯一变量、同步时刻、原始数据和结论等级。
3. 只动态验证一次最后的 `-Y 1 mm + q6 1.6 mrad` 候选，中途不引入新变量。
4. 如果 CLOSE 同时通过平移、倾斜、双侧接触和精确穿透指标，立即使用同步真实位姿生成 attach pose，并运行完整链路。
5. 如果失败，只允许根据该次证据修正一个参数族，再运行一次。
6. 最多三次动态实验或两小时。仍未通过则停止微调，在以下路线之间做结构性选择：
   - 重新设计指尖 collision 形状或两侧接触高度；
   - 以完成 demo 为优先，采用视觉可信但物理验收更宽松的 attachment 策略。
